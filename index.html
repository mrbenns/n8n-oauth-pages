This is a private, personal automation used with n8n to send automated email digests from my own Gmail account.

The automation uses the Gmail API only to send email messages that I have configured in my own n8n workflows. It is not offered as a public service and is not intended for use by other people.

No Google account data is sold, shared, or used for advertising. The automation only accesses the permissions required for the configured Gmail workflow.
